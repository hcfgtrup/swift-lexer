# Спецификация анализируемого языка Swift

## Лексемы
| Тип | Примеры |
|-----|---------|
| Ключевое слово | let, var, func, if, else |
| Идентификатор | x, myFunc, _temp |
| Число | 42, 3.14, 0xFF, 1e10 |
| Строка | "hello", "a\nb" |
| Оператор | +, ==, ->, ?? |
| Разделитель | (, ), {, }, ,, ;, : |

## Комментарии
- `// однострочный`
- `/* многострочный, поддерживает вложенность */`

## Ошибки
- Неизвестный символ
- Незакрытая строка
- Незакрытый многострочный комментарий
